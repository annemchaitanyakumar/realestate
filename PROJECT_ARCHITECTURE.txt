1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Paanchajanya Realty's web platform operates as a dual-layer architecture:

  1. Public Website (/) : A high-performance, lightweight PHP and modern
     Vanilla CSS/JS client portal delivering fast page loads and high SEO rankings.
     
  2. Administration Portal (/admin) : A full-stack Laravel 12 application
     powered by Livewire 3 and Tailwind CSS v4, handling leads, sliders,
     venture media, and administrative workflows.

3. COMMUNICATION ARCHITECTURE (FRONTEND TO BACKEND)
--------------------------------------------------------------------------------
This platform uses a Server-Side Rendered (SSR) Monolithic PHP architecture.
There is NO separate API or .env required for the public frontend:

  [ Visitor Browser ]
         │
         ▼  (1. HTTP GET /)
  [ Nginx Web Server (Port 80 / 443) ]
         │
         ▼  (2. Passes request to PHP-FPM)
  [ index.php ] ──includes──> [ includes/db.php ] ──PDO──> [ MySQL (127.0.0.1) ]
         │                                                        ▲
         │ (3. Queries 'sliders' table)                           │
         ▼ (4. Compiles and sends HTML/CSS)                       │
  [ Visitor Browser ]                                             │
         │                                                        │
         ▼ (5. Submits Contact Form via POST)                     │
  [ index.php ] ───INSERT INTO contact_submissions────────────────┘
                                                                  ▲
                                                                  │ (Reads leads)
  [ admin/ (Laravel 12 Dashboard) ] ──────────────────────────────┘

Key Files:
  - Database Connector: includes/db.php (Connects via PDO to MySQL)
  - Lead Capture      : index.php receives POST, inserts directly into
                        'contact_submissions' table.
  - Lead Management   : admin/ (Laravel 12) reads the same 'contact_submissions'
                        table for the admin dashboard.
